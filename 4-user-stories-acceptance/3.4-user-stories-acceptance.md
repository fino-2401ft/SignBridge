# 3.4 User Stories & Acceptance Criteria - User Stories và Tiêu chí Chấp nhận

## Tài liệu này trình bày chi tiết User Stories và Acceptance Criteria cho dự án SIGNBRIDGE, giúp định nghĩa rõ ràng các tính năng từ góc nhìn người dùng.

---

## 1. Tổng quan User Stories

### 1.1. Cấu trúc User Story

```
┌─────────────────────────────────────────────────────────────────┐
│                    USER STORY TEMPLATE                           │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Là một [vai trò],                                            │
│  Tôi muốn [hành động]                                        │
│  Để [lợi ích/mục tiêu]                                       │
│                                                                  │
│  Tiêu chí chấp nhận (Acceptance Criteria):                    │
│  ├── Given [ngữ cảnh]                                        │
│  ├── When [hành động]                                        │
│  └── Then [kết quả mong đợi]                                 │
│                                                                  │
└─────────────────────────────────────────────────────────────────┘
```

### 1.2. Quy ước đánh giá User Story

| Priority | Mô tả | Sprint |
|----------|--------|--------|
| P0 | Critical - Must have for MVP | Sprint 1-2 |
| P1 | High priority - Should have | Sprint 2-3 |
| P2 | Medium priority - Nice to have | Sprint 3-4 |
| P3 | Low priority - Future consideration | Backlog |

### US-001: Đăng ký tài khoản

```
┌─────────────────────────────────────────────────────────────────┐
│  USER STORY: US-001                                            │
├─────────────────────────────────────────────────────────────────┤
│                                                                  │

│  TIÊU CHÍ CHẤP NHẬN (Acceptance Criteria):                   │
│                                                                  │
│  AC-001.1: Đăng ký thành công                               │
│  ├── Given Người dùng mở ứng dụng lần đầu                   │
│  ├── When Người dùng nhập email hợp lệ và password đủ mạnh  │

│  ├── When Người dùng nhập email đó để đăng ký               │
```

```
├─────────────────────────────────────────────────────────────────┤
│                                                                  │
│  Là một người học đang thực hành,                             │

│  ├── When Hệ thống xử lý frame                               │
│  └── Then Trả về prediction trong < 100ms                     │
│                                                                  │
│  AC-021.2: Hiển thị kết quả dự đoán                          │
│  ├── Given Hệ thống nhận diện gesture thành công             │
```
