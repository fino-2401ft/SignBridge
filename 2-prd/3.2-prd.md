## 1. Product Overview

### 1.1 Product Name
**SIGNBRIDGE**

### 1.2 Product Tagline
AI-Driven Mobile App for Sign Language Recognition

### 1.3 Platform
- **Primary:** Android (API 26+, Android 8.0 Oreo and above)
- **Secondary:** iOS (Phase 2 - Out of Scope for MVP)

### 1.4 Target Release
- **MVP Release:** Q4 2026
- **Phase 2 Release:** Q2 2027 (iOS, additional sign languages)

### 1.5 Core Value Proposition

SIGNBRIDGE is a mobile application that bridges the communication gap between the deaf/hard-of-hearing community and hearing individuals by providing real-time American Sign Language (ASL) recognition and translation. The app enables users to learn ASL through structured courses, practice with AI-powered feedback, and communicate in real-time using their device's camera.

### 1.6 Problem Statement

According to the World Health Organization, over 430 million people worldwide have disabling hearing loss. The deaf community faces significant communication barriers in daily interactions with hearing individuals who do not understand sign language. Current solutions either require expensive interpreters, lack real-time translation capabilities, or fail to provide accessible learning tools for ASL acquisition.

SIGNBRIDGE addresses these challenges by:
- Providing real-time ASL-to-text/speech translation for daily communication
- Offering structured, gamified ASL learning with AI-powered practice feedback
- Operating with 100% on-device processing to ensure privacy and offline capability

7. System validates all fields
8. System creates account in Firebase Auth
9. System creates user document in Firestore with default values
10. System navigates to Login screen with email pre-filled
11. Toast displays "Registration successful"

**Field Validation Rules:**

| Field | Rules | Error Message |
|-------|-------|---------------|
| Email | Required, valid format (RFC 5322) | "Please enter a valid email address" |

#### FR-009: Dictionary Search

**Description:** Provides full-text search across ASL gesture vocabulary with real-time results.

**Actor:** Authenticated user

**Preconditions:**
- User is authenticated
- Dictionary data exists in Firestore

**Gesture Data Structure:**

```json
{
  "gestureId": "gesture-001",
  "word": "Hello",
  "alternatives": ["Hi", "Hey"],
  "category": "greetings",
  "videoUrl": "https://storage.../hello.mp4",
  "thumbnailUrl": "https://storage.../hello-thumb.jpg",
  "description": "Open hand wave near forehead",
  "difficulty": "beginner",
  "tags": ["basic", "common", "daily"]
}
```

**Main Flow:**
1. User navigates to Dictionary tab
2. System displays search bar and category grid
3. User taps search bar
4. Keyboard appears with placeholder "Search gestures..."
5. User types query (minimum 1 character)
6. Results update in real-time (debounced 300ms)
7. Matching gestures display as cards
8. User taps a card
9. Detail screen opens with full video

**Search Algorithm:**

```typescript
function searchGestures(query: string): Gesture[] {
  const normalizedQuery = query.toLowerCase().trim();
  
  return gestures
    .map(gesture => {
      let score = 0;
      
      // Exact match
      if (gesture.word.toLowerCase() === normalizedQuery) {
        score = 100;
      }
      // Prefix match
      else if (gesture.word.toLowerCase().startsWith(normalizedQuery)) {
        score = 80;
      }
      // Contains match
      else if (gesture.word.toLowerCase().includes(normalizedQuery)) {
        score = 60;
      }
      // Alternative match
      else if (gesture.alternatives.some(alt => 
        alt.toLowerCase().includes(normalizedQuery)
      )) {
        score = 50;
      }
      // Fuzzy match (Levenshtein distance ≤ 2)
      else if (levenshteinDistance(normalizedQuery, gesture.word.toLowerCase()) <= 2) {
        score = 30;
      }
      
      return { gesture, score };
    })
    .filter(result => result.score > 0)
    .sort((a, b) => b.score - a.score)
    .map(result => result.gesture);
}
```

**Match Priority:**

| Priority | Match Type | Score | Example |
|----------|-----------|-------|---------|
| 1 | Exact match | 100 | "hello" matches "hello" |
| 2 | Prefix match | 80 | "he" matches "hello" |
| 3 | Contains | 60 | "llo" matches "hello" |
| 4 | Alternative | 50 | "hi" matches "hello" (alternatives) |
| 5 | Fuzzy | 30 | "helo" matches "hello" |

**Search Result Card:**


#### FR-013: AI Gesture Recognition

**Description:** Continuously processes camera frames to recognize ASL gestures using MediaPipe and TensorFlow Lite.

**Actor:** System (automated)

**AI Processing Pipeline:**

```
┌─────────┐    ┌────────────┐    ┌──────────┐    ┌─────────┐    ┌────────┐
│ Camera  │───▶│ Capture    │───▶│ MediaPipe│───▶│ TFLite  │───▶│  UI    │
│ Frames  │    │ 30 FPS     │    │ Hand     │    │ Infer   │    │ Update │
└─────────┘    └────────────┘    │ Landmarks │    │ <100ms  │    └────────┘
                                  └──────────┘    └─────────┘
```

**Step-by-Step Processing:**

| Step | Component | Input | Output | Latency |
|------|-----------|-------|--------|---------|
| 1 | Camera | Raw frame | NV21 buffer | - |
| 2 | Preprocess | NV21 buffer | RGB tensor (224x224) | 5ms |
| 3 | MediaPipe | RGB tensor | 21 hand landmarks (x,y,z) | 20ms |
| 4 | Normalize | Raw landmarks | Normalized tensor | 5ms |
| 5 | TFLite | Normalized tensor | Prediction (label, confidence) | 50ms |
| 6 | Score | Prediction, landmarks | Final score (0-100) | 10ms |
| 7 | UI | Score, feedback | Display update | 10ms |
| **Total** | | | | **100ms** |

**MediaPipe Hand Landmarks (21 points):**

```
        8   12  16  20          Wrist
        │    │   │   │           0
        7   11  15  19          Thumb: 1,2,3,4
        │    │   │   │           Index: 5,6,7,8
        6   10  14  18          Middle: 9,10,11,12
        │    │   │   │           Ring: 13,14,15,16
        4   12  16  20          Pinky: 17,18,19,20
```

**Confidence Score Calculation:**

```typescript
function calculateScore(
  prediction: { label: string; confidence: number },
  landmarks: Landmark[]
): number {
  // Base score from model confidence
  const baseScore = prediction.confidence * 100;
  
  // Visibility penalty (if hand partially visible)
  const avgVisibility = calculateAvgVisibility(landmarks);
  const visibilityPenalty = avgVisibility < 0.7 ? (1 - avgVisibility) * 30 : 0;
  
  // Stability bonus (consistent prediction over frames)
  const stability = calculateStability(prediction, windowSize = 5);
  const stabilityBonus = stability > 0.8 ? 5 : 0;
  
  // Hand position bonus (centered in frame)
  const positionBonus = isHandCentered(landmarks) ? 3 : 0;
  
  // Calculate final score (clamped 0-100)
  const finalScore = Math.min(100, Math.max(0, 
    baseScore - visibilityPenalty + stabilityBonus + positionBonus
  ));
  
  return Math.round(finalScore);
}
```

## 8. Assumptions

The following assumptions underpin the requirements:

| # | Assumption | Impact if Wrong |
|---|------------|-----------------|
| 1 | Users have front-facing cameras | Camera-based features unusable |
| 2 | Users have stable internet (4G+) | Video content slow/unavailable |
| 3 | Initial dataset: 28 gestures, 3 paths | Scope may need adjustment |
| 4 | AI model accuracy ≥ 90% | User trust issues |
| 5 | On-device processing acceptable | Privacy concerns |
| 6 | Android 8.0+ is sufficient coverage | Excludes older devices |
| 7 | TFLite model size < 50MB | Storage/load issues |
| 8 | Users consent to camera access | Core feature unusable |
| 9 | Firebase pricing is acceptable | Cost overrun |
| 10 | No regulatory concerns (HIPAA, GDPR) | Compliance issues |

## 9. Acceptance Signals

### Critical User Flows

| Flow | Steps | Success Criteria |
|------|-------|------------------|
| Registration | Open app → Sign up → Verify email → Login | Account created, no errors |
| Learning | Browse paths → Start lesson → Watch video → Complete | XP awarded, progress updated |
| Practice | Open practice → Select gesture → Sign → View feedback → End | Score displayed, record saved |

```
register → login → browse learning path → 
complete lesson → practice gesture → 
translate ASL in real-time → logout
```
